# Security Policy

## Supported versions

Birdr is under active development. Security fixes are made on the latest
version of the `main` branch and are released to the live website and current
mobile apps. Older releases are not maintained separately.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue,
discussion, pull request, or social-media post.

Email [info@birdr.pro](mailto:info@birdr.pro) with the subject **Security
report**. Include, where possible:

- the affected URL, app version, API endpoint, or commit;
- a clear description of the vulnerability and its possible impact;
- steps or a minimal proof of concept that let us reproduce it;
- any suggested mitigation; and
- how you would like to be credited.

Do not include credentials, personal data, or data belonging to other users in
the report. If the report contains sensitive material that should not be sent
by ordinary email, ask for a secure communication channel first.

We aim to acknowledge reports within seven days. After reproducing and
assessing the issue, we will share a status update and coordinate a reasonable
disclosure date with you. Response and release timing will depend on severity
and on mobile-store review times.

## Research guidelines

When investigating a possible vulnerability:

- use your own accounts and test data;
- avoid accessing, changing, or deleting other people's data;
- avoid privacy violations, disruption, denial of service, spam, and automated
  high-volume testing;
- stop testing and report the issue if you encounter personal data or secrets;
  and
- give us a reasonable opportunity to investigate and release a fix before
  publishing details.

Good-faith research that follows these guidelines is welcome. This policy does
not authorize actions that violate applicable law or the terms of third-party
services used by Birdr, and Birdr does not currently offer a bug bounty.

## Other reports

For ordinary bugs and feature requests, use the
[GitHub issue tracker](https://github.com/birdr-app/birdr/issues). Questions
and general feedback can also be sent to [info@birdr.pro](mailto:info@birdr.pro).
