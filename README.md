# Birdr

**Learn to identify birds yourself.**

Birdr is a free and open-source bird identification training app for iPhone, Android and the web. Instead of identifying a bird for you, Birdr helps you practise the field marks, sounds and lookalikes needed to recognise it yourself.

[Open Birdr](https://birdr.pro/) · [Play in your browser](https://birdr.pro/play/) · [How it works](https://birdr.pro/site/how-it-works/) · [Live usage data](https://birdr.pro/data/games-played/) · [Community](https://birdr.pro/site/community/)

## Current status

Birdr is live, free to use and under active development. The mobile apps and browser version use the same account and learning progress.

The current focus is on improving media quality, accessibility and localisation; expanding personalised practice; and learning from birders and bird clubs around the world.

This repository is being prepared as the public home of the Birdr source code. The project is licensed under GPL-3.0; source code and contributor documentation will be added as they are readied for publication.

## Usage

Usage is growing quickly:

- **14,313 scored game sessions** between 1 October 2025 and 4 September 2026.
- **4,275 games by 573 distinct players in August 2026**, more than three times the number of games played in July.
- In the first four days of September 2026, players completed **1,334 games**.
- Games have been played using **142 country and territory lists**.

These figures count distinct game sessions and players with scores. See the [interactive games-played dashboard](https://birdr.pro/data/games-played/) for the latest figures, trends and geographic spread.

## Features

### Flexible bird quizzes

- Practise with real **photos, video and bird sounds**.
- Choose a country so the quiz uses birds relevant to that place.
- Play 10, 20, 50 or 100 questions.
- Filter by taxonomic order or family.
- Use common bird names in multiple languages or scientific names.
- Limit sound quizzes to passerines when desired.

### Five difficulty levels

- **Beginner** — familiar, distinctive birds with easy multiple choice.
- **Novice** — a broader selection of regularly occurring species.
- **Advanced** — regular species with similar-looking alternatives.
- **Pro** — difficult lookalikes, including rare birds.
- **Expert** — type the bird name yourself, with rare species included.

### Personalised learning

- **My Tricky Birds** remembers missed species and confusing pairs, then turns them into focused practice.
- **My Checklist** shows which birds you have identified correctly and which still need work.
- Review every answer after a game and learn what to notice next time.
- Explore species pages and direct comparisons between commonly confused birds.

### Challenges and social play

- **Country Challenges** provide a structured path from distinctive beginner birds to expert lookalikes.
- **Daily Challenges** let friends practise the same set of birds.
- **Live multiplayer** supports two or more players, with faster correct answers earning more points.
- **Flocks** give bird clubs, friends and travel groups shared quizzes and private leaderboards.
- High-score tables make individual quiz results comparable.

## How to help

Birdr is a small independent project, and contributions from birders are especially valuable:

- [Report a bug or suggest a feature](https://github.com/birdr-app/birdr/issues).
- Flag an incorrect or unusable photo, video or sound during a quiz.
- Review bird photos for a country you know well.
- Improve descriptions that explain how to distinguish lookalike species.
- Share Birdr with a bird club or create a Flock for your group.

Questions and feedback are also welcome at [info@birdr.pro](mailto:info@birdr.pro).
